# Week 3

Materi lanjutan Streamlit dan dashboard data gempa bumi dari USGS.

## Isi

- `app.py` - dashboard gempa dengan progress bar, cache data, histogram, filter magnitude, dan peta.
- `pages/1_Progress_Bar.py` - contoh progress bar.
- `pages/2_Caching_Demo.py` - contoh caching.
- `pages/3_Session_callback.py` - contoh session state dan callback.
- `test.ipynb` - notebook latihan.

Dashboard mengambil data dari internet melalui URL USGS, sehingga koneksi internet diperlukan.

## Menjalankan

```bash
streamlit run app.py
```
