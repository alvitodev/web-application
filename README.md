# Praktik Aplikasi Web

Kumpulan latihan dan tugas praktikum aplikasi web menggunakan Python dan Streamlit.

## Navigasi

- [Latihan](latihan/README.md) - aplikasi Streamlit pertama.
- [Week 2](week-2/README.md) - komponen dasar, dataframe, multipage, dan media.
- [Week 3](week-3/README.md) - progress bar, cache, callback, dan dashboard gempa.

## Menjalankan Aplikasi

Aktifkan virtual environment pada folder materi yang ingin digunakan, lalu jalankan:

```bash
streamlit run nama_file.py
```
