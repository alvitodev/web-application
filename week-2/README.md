# Week 2

Materi dasar Streamlit untuk membuat tampilan aplikasi dan halaman multipage.

## Isi

- `hello.py` - contoh komponen teks, metric, dan columns.
- `dataframe.py` - menampilkan data barang menggunakan Pandas.
- `main_page.py` - contoh halaman utama dan sidebar.
- `pages/` - halaman tambahan aplikasi.
- `media.py` - contoh penggunaan media.

## Menjalankan

Untuk menjalankan contoh tertentu:

```bash
streamlit run hello.py
```

Untuk menjalankan aplikasi multipage:

```bash
streamlit run main_page.py
```
